### 🚀 Como ativar o site no GitHub Pages:
1. Crie um repositório no GitHub com o nome `meu-site`.
2. Envie os arquivos (`index.html` e `.nojekyll`) para a branch principal (`main`).
3. No GitHub, acesse **Settings** > **Pages**.
4. Em **Build and deployment** > **Source**, selecione **Deploy from a branch**.
5. Selecione o branch **main** e a pasta **/ (root)** e clique em **Save**.
6. Aguarde cerca de 1 a 2 minutos e acesse seu link!
